# Canon TDD for Chrome Extensions

- Create and maintain a Test Plan immediately before implementation.
- Work Red, Green, Refactor one behavior at a time.
- Use pure TypeScript unit tests for KML and state; use sanitized HTML fixtures for selector logic; test popup/content-script boundaries separately.
